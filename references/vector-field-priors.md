# 网格与向量场参考

具有空间结构的流图不能仅用几条孤立的时间曲线替代。已有九个基础组件保留为功能测试，不代表适合所有论文的视觉方向。新方案应实际查看目标参考，并结合目标论文的科学要求重建。

## 二维分布与三维网格

二维分布可以以**柔和的不规则分布色块、疏密有层次的虚线等高线、少量局部方向箭头、样本点**为主体，并根据参考协调 Comic 文字或衬线数学符号。二维不默认铺满密集网格或整齐箭头阵列。网格仅在确有解释作用时加入，并弱化。

图内颜色需要有对比但不荧光；例如浅桃色填充与赭色轮廓可以形成柔和层次。参考中的红/绿样本与箭头不能未经科学解释照搬为通用正负含义。轨迹、更新方向、速度向量也不能混称。保留空间结构，删去参考图特定任务的标签及更新公式，除非目标论文确实需要。

三维表达可使用开放的浅灰弯曲网格、少量可区分点簇和半透明分布云。二维与三维是不同构图系列，不把平面图直接挤压拉伸为伪 3D。参考和认可记录应由当前使用者提供并保存在私人目录，仓库不预置某位使用者的认可状态。旧基础示例不应默认注入此类生图输入。

## 推荐构图及取舍

1. **变形网格 + 稀疏方向箭头 + 少量高亮轨迹（需要网格时的首选）**：同时表现空间如何改变和局部如何运动。适合作为方法图中的中型可编辑组件；网格线细、箭头有规律、轨迹对比明显，不用大标题撑画面。若目标参考更偏分布轮廓，应选择相应表达。
2. **固定坐标网格 + 方向场**：结构较清楚，适合紧凑单模块；只能说明当前位置的方向，不能暗示网格本身被输运。
3. **网格 + 密度等高线**：适合解释分布输运；信息更多，缩入方法图后容易拥挤，密度必须有来源，不宜默认加入。

网格、方向箭头、主轨迹分别使用低、中、高视觉权重。保留 Comic/Roman/Modern 可选，不把一种配色强制用于所有论文。空间结构优先于换字体。

## 必须保持的科学区别

- 同一帧中的横纵轴可以是二维状态；多个时间切片才表示时间推进。不能随意混合成标量时间曲线。
- 若称为随流变形的网格，所有网格点、样本与轨迹必须来自同一映射/速度场。网格不能无解释地折叠、相交或撕裂。
- 图像生成可以探索线条层次、构图和颜色。正式可编辑图中的几何由已说明的映射或明确示意规则确定，不从生成图片反推科学结论。
- `dx/dt=-x` 的现有示例是标量方程。需要二维流动时另写科学 brief，不为匹配外观擅自变更它。
- ODE、SDE 和 Flow Matching 不共用一套任意轨迹：SDE 区分漂移与随机实现；Flow Matching 区分条件训练路径与采样速度场。
